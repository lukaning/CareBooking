# EmBeLife

Native iOS (SwiftUI) MVP of the EmBeLife care-booking design system.

## Scope

- Sign In / Sign Up
- New-user onboarding (role + language → services → location)
- Home matches feed + filters sheet
- Book a Provider sheet
- Profile (empty + booked states)
- Tab placeholders: Messages, Notes, Payment

## Open in Xcode

1. Open `EmBeLife.xcodeproj`
2. Select an iPhone simulator
3. Run (⌘R)

Requires Xcode 15+ / iOS 17+.

## Notes

- System SF Pro is used instead of Plus Jakarta Sans / Inter / Poppins from Figma (better Dynamic Type + SF Symbol alignment).
- Brand orange `#F15925` is the accent / primary CTA color from the file.
- Auth and booking are local demo state only (no backend).
